# Books Manage VS Code Extension

Personal VS Code client for the local `books_manage` backend.

## Development

```bash
cd vscode-extension
npm install
npm run compile
```

Open this folder in VS Code, press `F5`, and run the extension host.

Default backend:

```text
http://localhost:3001/api
```

Use `Books Manage: Login` before loading the tree if the backend auth gate is enabled.
